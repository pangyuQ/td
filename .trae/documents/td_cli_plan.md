# 个人待办 CLI 工具 (td) 开发计划

## 1. 概述
本项目旨在使用 Go 语言开发一个极其轻量化、极简的 Windows 个人待办事项命令行工具（CLI）。工具名称为 `td`，主打“零外部依赖”或“极少依赖”，实现快速启动和极小的体积。

## 2. 当前状态分析
目前工作区为空，需要从零开始搭建项目结构和初始化配置。

## 3. 技术栈选择（主打轻量化）
- **编程语言**: Go 
- **数据存储**: JSON 文件 (`~/.td.json`)
- **核心依赖**:
  - **完全移除重量级框架**（如 Cobra、Viper 等），改用 Go 标准库 `os.Args` 或 `flag` 进行命令解析。
  - **极简交互**：移除重量级 TUI 库（如 Survey/Bubbletea），改用标准库 `bufio` 和 `fmt.Scan` 实现轻量级的交互式问答（例如提示输入 ID 来完成或删除）。
  - （可选）仅引入极轻量的颜色库（或使用 ANSI 转义序列）来美化输出。

## 4. 详细设计与提议更改

### 4.1 数据模型与存储
- **数据结构**: 
  ```go
  type Task struct {
      ID          int       `json:"id"`
      Content     string    `json:"content"`
      IsCompleted bool      `json:"is_completed"`
  }
  ```
- **存储逻辑**:
  - 使用 `os.UserHomeDir()` 获取主目录。
  - 标准库 `encoding/json` 进行读写 `~/.td.json`。

### 4.2 极简命令设计
直接解析 `os.Args[1]` 来区分命令：
- **`td add <内容>` 或 `td a <内容>`**: 添加新待办。支持多单词，如 `td add 买牛奶和面包`。
- **`td list` 或 `td ls`**: 打印待办列表。按格式输出 `[ ] 1. 买牛奶` 和 `[x] 2. 跑步`。
- **`td do <id>` 或 `td d <id>`**: 完成指定 ID 的待办（替代原有的 complete）。
  - **轻量交互**: 若仅输入 `td do`，程序会先打印未完成的列表，然后提示 `请输入要完成的待办 ID: `，等待用户输入。
- **`td rm <id>`**: 删除指定 ID 的待办（替代原有的 delete）。
  - **轻量交互**: 若未输入 ID，同样打印列表并提示输入 ID 进行交互式删除。

### 4.3 项目结构（极简扁平化）
```text
/workspace/
├── main.go            # 包含主入口和命令路由
├── task.go            # 包含数据模型和 JSON 读写逻辑
├── cli.go             # 包含具体的命令执行逻辑 (add, list, complete 等)
├── go.mod             # Go 模块定义
└── README.md
```

## 5. 验证与测试步骤
1. 初始化项目 `go mod init td`。
2. 编写无任何第三方依赖的代码，确保体积最小化。
3. 依次测试 `add`, `list`, `complete`, `delete` 命令。
4. 测试省略 ID 参数时的轻量交互式输入提示是否正常工作。
5. 编译并验证生成的可执行文件大小和运行速度。
